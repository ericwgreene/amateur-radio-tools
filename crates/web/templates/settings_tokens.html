API Tokens

Personal access tokens let an external application — a logging program, a script, your station computer — record contacts through the REST API on your behalf. Treat them like passwords.

Using a token

Send the token as a Bearer credential. For example, to log a contact: 

curl -X POST {{ base_url }}/api/v1/contacts \
  -H "Authorization: Bearer <your-token>" \
  -H "Content-Type: application/json" \
  -d '{"callsign":"W1AW","band":"20m","mode":"SSB","frequency_mhz":14.074}'

Other endpoints: GET /api/v1/contacts (list yours) and GET /api/v1/me (verify a token).
